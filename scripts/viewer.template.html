Effect estimate

Both arms run the same cohort with the same hidden latents, and every random draw is keyed by event identity rather than by position in a stream — so a case that heals itself at hour 137 does so in every arm. The interval is a paired bootstrap: it resamples cases, each carrying both arms' outcomes. Resampling the arms independently would throw away precisely the variance reduction that pairing buys.

Spread

What the interval is made of

The interval above is a summary of this: resamples of the cohort, each one a complete re-run of the paired comparison. The interval is simply the 2.5th and 97.5th percentiles of the pile. Drawing it shows what a bracket cannot — whether the estimate is a tight cluster or a smear, and how far the whole distribution sits from the no-effect line.

Sensitivity

Does the result survive its own assumptions?

The self-heal rate is our own prior, not a quoted figure — which is the first objection any careful reader should raise. So it is swept ±50%, and the same estimate is re-drawn at each point. What matters is not the size of the effect but whether it keeps its sign. Two more parameters are swept beside it, so the page cannot be accused of sweeping only the one that flatters it.

Refusals

Twelve rules run on every action — nine operational, three RBI. The engine does not short-circuit: every rule runs even after one has denied, and the ledger records each verdict. The refusals are the audit trail's interesting half.

Counts sum to more than the refused actions, because a single action is objected to by every rule that disagrees with it rather than only the first. The RBI rules are the emphasised rows.

One refusal, verbatim from the ledger

Each entry carries the hash of the entry before it. The ledger has no update path and no delete path — not by convention, by absence.







  
Not measured

  

    
There is no agent-arm figure on this page

    
The agent layer is built. It implements a policy-gated tool_runner
    loop over six tools, and its tests pass with no API key present — including proof
    that a denied tool never reaches the transport, and that a recorded plan replays to
    identical actions.

    
The ANTHROPIC_API_KEY it was designed around never arrived.
    In the final hours a Groq-hosted open model (openai/gpt-oss-120b)
    was wired in as an alternative planner. The gate lives inside the tool functions,
    not in the model loop, so the six tools and every rule screening them are identical
    whichever model is planning.

    
Cassettes exist for 5 of the 500 cases, and no figure on this page comes
    from them. Five cases cannot support a bootstrap interval, and a five-case run
    is not comparable to the 500-case table. Quoting a number from it would be the exact
    claim this page was built to argue against.

    
An observation, not a result: across those 5 cases the agent took 6 actions —
    4 retries, 1 message, 1 close — and one of its three recoveries came from a
    contact rather than a retry, a move the retry-only baseline cannot
    make. None of the 6 was denied, so the pilot exercised the happy path
    only and is no evidence the gate binds live. That evidence stays where it was: the
    628 refusals above, 12 rules on every one of 1,270 checks, and a test proving a denied
    tool never reaches the transport.

    
The measurement spine never depended on any of this. Holdout
    versus treated is a complete, reproducible, interval-bounded result, and the agent arm
    slots into the same harness the moment a full set of cassettes exists.
